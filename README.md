# Villa Aurora

Sito web dimostrativo per una struttura ricettiva immaginaria in stile mediterraneo, realizzato con HTML, CSS e JavaScript vanilla.

## Anteprima locale

Apri `index.html` nel browser oppure usa l'estensione Live Server di Visual Studio Code.

## Pubblicazione con GitHub Pages

Il repository include un workflow GitHub Actions in `.github/workflows/pages.yml`.

1. Apri **Settings → Pages** nel repository.
2. In **Build and deployment**, seleziona **GitHub Actions** come Source.
3. Il workflow pubblicherà automaticamente il sito a ogni push sul branch `main`.
4. Controlla la scheda **Actions** per verificare il completamento della pubblicazione.

## Prima di usare il progetto per un'attività reale

- Sostituisci nome, testi, località, immagini e informazioni illustrative con contenuti autorizzati dal proprietario.
- Il modulo nella sezione contatti è solo dimostrativo: non invia né memorizza prenotazioni. Collega un backend o un servizio di booking prima di raccogliere richieste reali.
- Configura un dominio personalizzato, un recapito reale e le informative necessarie (privacy e cookie, se applicabili).
- Verifica licenze e condizioni d'uso delle immagini e dei servizi esterni.

## Tecnologie

- HTML5 semantico
- CSS responsive
- JavaScript vanilla
- Google Fonts (DM Sans e Playfair Display)
- Immagini remote da Unsplash

> Progetto portfolio / demo. Villa Aurora e le informazioni presentate non rappresentano una struttura ricettiva reale.
